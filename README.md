# \# NutriSalud

# 

# Sistema de gestión de servicios nutricionales.

# 

# \## Requisitos de instalación

# 

# \- Windows 10 o superior.

# \- WAMP Server.

# \- Git.

# \- PHP.

# \- MariaDB o MySQL.

# 

# \## Instalación

# 

# 1\. Descargar el repositorio desde GitHub:

# 

# &#x20;  https://github.com/UTVAM-Software/2026-III-AdoptCan

# 

# 2\. Colocar la carpeta del proyecto en:

# 

# &#x20;  `C:\\wamp64\\www\\`

# 

# 3\. Ejecutar el archivo `instalar.bat` como administrador.

# 

# 4\. Verificar que Apache y MariaDB estén funcionando.

# 

# 5\. Comprobar la configuración de conexión a la base de datos en `config/conexion.local.php`.

# 

# 6\. Abrir el sistema desde el navegador:

# 

# &#x20;  `http://localhost/2026-III-AdoptCan/`

# 

# \## Verificación del sistema

# 

# Una vez instalado:

# 

# \- Comprobar que aparezca la pantalla de inicio de sesión.

# \- Iniciar sesión con un usuario registrado.

# \- Verificar que los módulos aparezcan según los permisos asignados.

# \- Comprobar que la información se consulte correctamente.
